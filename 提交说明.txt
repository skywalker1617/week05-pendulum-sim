【为什么 GitHub 推送需要你操作】
GitHub 上的仓库属于个人账号，推送必须使用你本人的凭据。
本机没有保存任何 GitHub 登录态，因此这一步无法由 AI 代劳。

------------------------------------------------------------
【方式一：双击脚本（30 秒，推荐）】
------------------------------------------------------------
1. 双击本文件夹里的  push_to_github.bat
2. 按提示输入你的 GitHub 用户名
3. 粘贴 Personal Access Token（右键粘贴，输入时不显示是正常的）
4. 等待约 10 秒，脚本会自动：
   · 在你的 GitHub 上创建仓库 week05-pendulum-sim
   · 推送全部 4 次提交
   · 打印仓库网址并自动用浏览器打开

Token 获取方法（只需一次）：
GitHub 右上头像 → Settings → 左下 Developer settings
→ Personal access tokens → Tokens (classic) → Generate new token (classic)
→ Note 填 week05 → 勾选【repo】整个大类 → Generate token
→ 复制 ghp_ 开头的那串（只显示一次）

交完作业后建议回到该页面点 Revoke 删除 token。

------------------------------------------------------------
【方式二：手动命令】
------------------------------------------------------------
cd week05_pendulum_sim
git remote add origin https://github.com/<你的用户名>/week05-pendulum-sim.git

（先在 GitHub 网页手动 New repository，名称填 week05-pendulum-sim，
  不要勾选 Add README / .gitignore / license，否则会冲突）
